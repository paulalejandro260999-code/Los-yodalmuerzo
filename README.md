# Los Yodalmuerzos

Sitio académico de almuerzos y viandas caseras. Presenta cinco platos con fotografías e ingredientes, planes de viandas, reseñas ficticias y un formulario de contacto.

## Tecnologías
HTML semántico, CSS externo (css/styles.css), Google Fonts (Poppins), Flexbox en productos, Grid en reseñas y media queries para contacto y otras áreas. Sin JavaScript.

## Abrir el proyecto
Extraer toda la carpeta, abrirla en Visual Studio Code y abrir index.html en el navegador o mediante Live Server. Las fotos funcionan localmente; Google Fonts necesita conexión y tiene una fuente de respaldo.

## Pendiente antes de entregar
- Probar el formulario configurado con un mensaje propio y confirmar su recepción en Formspree y el correo.
- Publicar el repositorio público y activar GitHub Pages; probar un envío desde el sitio publicado y confirmar su recepción.
- Completar la autoevaluación y entregar los dos enlaces en el campus.

El formulario está conectado al endpoint https://formspree.io/f/xbgddgnb con method="POST", campos name, email y message y validación HTML. Su recepción real todavía debe probarse.

## Publicar en GitHub Pages
1. Crear un repositorio público y subir el contenido de esta carpeta, con index.html en la raíz del repositorio.
2. En el repositorio: Settings > Pages > Build and deployment > Source: Deploy from a branch.
3. Elegir main y /(root); guardar.
4. Abrir la URL que GitHub muestre y revisar las imágenes, navegación y formulario.
