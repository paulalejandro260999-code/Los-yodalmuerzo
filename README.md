# Los Yodalmuerzos

Sitio académico de almuerzos y viandas caseras
Página de almuerzos y/o viandas.

Incluye un menú con variedad de platos, reseñas de ejemplo y un formulario de contacto conectado con Formspree.

Desarrollado con HTML y CSS, flexbox, Grid y media queries para adaptarse a dispositivos moviles (celulares)
